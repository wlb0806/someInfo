如何用 Eos 清理 Mac 上的 Xcode 缓存

Xcode 的构建产物、模拟器缓存和归档保存在不同位置。用 Eos 先看空间占用，找出可以重新生成的文件，再复核哪些会移入废纸篓。

本篇内容

  1. 开始智能扫描，打开开发垃圾
  2. 优先选择可以重新生成的文件
  3. 复核清理范围，先移入废纸篓

哪些 Xcode 文件需要复核？

扫描结果清理后的影响
Derived DataXcode 会重新生成构建产物，下次构建可能更慢。
模拟器缓存模拟器工具会按需重新生成，下次启动可能更慢。
旧设备支持文件移除之前，先确认还需要哪些设备和 iOS 版本。
Xcode Archives归档可能包含还需要的构建或调试符号。Eos 默认不会勾选。

1. 开始智能扫描，打开开发垃圾

打开 Eos，开始智能扫描。扫描完成后，从结果里进入「开发垃圾」，按类别查看 Xcode 和其他开发工具的文件。

留意 Xcode 的 Derived Data、模拟器缓存和旧设备支持文件。能看到哪些类别取决于这台 Mac 上可供扫描的内容。

2. 优先选择可以重新生成的文件

第一次清理，可以先查看还能重新构建的项目的 Derived Data。Xcode 下次构建时会重新生成，第一次构建可能更慢。

单独检查模拟器缓存和旧设备支持文件。还需要的归档，或不确定有没有副本的归档，先保留。

3. 复核清理范围，先移入废纸篓

打开清理确认，逐项核对已选类别和大小。取消不打算清理的项目，确认后选择移入废纸篓。

建议先重新构建项目或打开模拟器，确认可正常使用。废纸篓清空之前，移进去的文件可能仍占用磁盘空间。
